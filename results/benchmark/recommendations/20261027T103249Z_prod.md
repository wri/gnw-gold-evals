# BENCHMARK 2026-draft-5: the first report after the "could this mislead?" review, 27 October 2026

**Combined, canonical, draft version. This is the draft-5 report the FE
AI accuracy scorecards page shows, once the branch is pushed.** Before this
run AJ asked for a critical review of all 269 draft-4 questions, judged by one
question: could this answer mislead the user? The review (claude.ai artifact
68PEmch8CvCEJwgB2xtmTy, "BENCHMARK draft-4 critical review") found that 143
questions had nothing checking what the answer says, and that some checks
failed answers that would mislead no one. Its recommendations were applied
on `benchmark-draft-5` (`cases/challenge/README.md`, "Draft-5 review") and
`2026-draft-5` replaces draft-4.

**Check semantics changed**, so this report is not comparable with draft-4
point for point:

- New checks that count: `figure_match` (the asked figure, recomputed from
  the table the agent itself pulled, must be in the reply), `figure_claim_match`
  (the conclusion the data supports; fails only a reply that states the
  opposite) and `answer_period_match` (the answer's figures are for the asked
  period). Data quality is out of scope.
- `date_extraction` passes a pull that contains the asked window, reads the
  pulled window when no call carries dates, and now scores rolling windows:
  a bug had left every `{run-14d}` window unscored since tokens were added.
- `web_fallback` fires only when no data was pulled.
- New fair-alternative syntax (per-area `/` records, `|` in forest filters
  and nudge offers) and about 210 revised expectations.

## What the new checks caught

Genuine catches, answers that could mislead:

- `ch-mon-011`: three-year alert totals given for "recently" (figure and
  period both fail on every attempt).
- `ch-trend-052`, `ch-quant-189`: replies whose figures do not match the
  agent's own pulled table (607,651 ha against 3.39 Mha; department totals
  6% off).
- `ch-trend-050`, `ch-trend-001`: replies implying the opposite of the data
  (a lower second half of 2024; a downward trend when 2023 was above 2015).
  `ch-trend-001` is borderline: the replies say loss "settled lower" after the
  2016 peak, which is true against 2016. **AJ to judge.**
